1. O que é CSS Grid?

CSS Grid é um sistema de layout que permite organizar elementos em linhas e colunas. Ele facilita a criação de estruturas organizadas para páginas e aplicações. 

.container {
    display: grid;
}

2. Criando colunas

A propriedade grid-template-columns define a quantidade e o tamanho das colunas. 

.container {
    display: grid;
    grid-template-columns: 1fr 1fr 1fr;
    gap: 10px;
}

A unidade fr divide o espaço disponível em frações. Neste exemplo, as três colunas possuem a mesma proporção.

3. Criando linhas

A propriedade grid-template-rows define a altura das linhas da grade. 

.container {
    display: grid;
    grid-template-columns: 1fr 1fr;
    grid-template-rows: 80px 140px;
    gap: 10px;
}

4. Espaçamento entre elementos

A propriedade gap define a distância entre as linhas e colunas. 

.container {
    display: grid;
    grid-template-columns: repeat(3, 1fr);
    gap: 20px;
}

Também podemos utilizar row-gap para o espaço entre linhas e column-gap para o espaço entre colunas.

5. Elementos ocupando mais espaço

As propriedades grid-column e grid-row permitem que um elemento ocupe mais de uma coluna ou linha.

6. Grid responsivo

As funções repeat(), auto-fit e minmax() ajudam a adaptar as colunas ao espaço disponível na tela. 

.container {
    display: grid;
    grid-template-columns:
        repeat(auto-fit, minmax(150px, 1fr));
    gap: 10px;
}

7. Quando utilizar Grid?

  • Galerias de imagens.
  • Painéis de informações.
  • Layouts completos de páginas.
  • Organização de cartões em linhas e colunas.

8. Atividade prática

Crie uma grade que:

  • Tenha três colunas.
  • Possua duas ou mais linhas.
  • Utilize gap.
  • Tenha um elemento ocupando duas colunas.
