1. O que é Flexbox?

O Flexbox é um recurso do CSS utilizado para organizar, alinhar e distribuir elementos dentro de um contêiner. Ele facilita a criação de layouts flexíveis e responsivos. 

.container {
    display: flex;
}

2. Direção dos elementos

A propriedade flex-direction define a direção em que os elementos serão organizados.

  • row: organiza os elementos em linha.
  • column: organiza os elementos em coluna.
  • row-reverse: inverte a ordem horizontal.
  • column-reverse: inverte a ordem vertical.

.container {
    display: flex;
    flex-direction: row;
}

3. Centralização com Flexbox

O Flexbox é uma das formas mais modernas e simples de centralizar elementos, tanto horizontal quanto verticalmente.

Centro
.container {
    display: flex;
    justify-content: center;
    align-items: center;
}

4. Alinhamento e espaçamento

A propriedade justify-content distribui os elementos no eixo principal. A propriedade align-items controla o alinhamento no eixo transversal.

  • center: centraliza os elementos.
  • flex-start: alinha no início.
  • flex-end: alinha no final.
  • space-between: distribui o espaço entre os itens.

.container {
    display: flex;
    justify-content: space-between;

}

5. Flex-wrap e gap

A propriedade flex-wrap permite que os elementos passem para outra linha quando não houver espaço suficiente. A propriedade gap define o espaço entre eles.

.container {
    display: flex;
    flex-wrap: wrap;
    gap: 10px;
}

6. Propriedades intermediárias

O Flexbox também permite controlar o tamanho e o comportamento individual dos elementos.

  • flex-grow: permite que o item cresça.
  • flex-shrink: controla sua redução.
  • flex-basis: define o tamanho inicial.
  • align-self: altera o alinhamento de um item.
.item {
    flex: 1 1 150px;
}

Nesse exemplo, o elemento pode crescer ou diminuir, começando com um tamanho de referência de 150 pixels.

7. Quando utilizar Flexbox?

  • Menus de navegação.
  • Alinhamento de botões.
  • Centralização de elementos.
  • Organização de cartões.
  • Layouts responsivos.

8. Atividade prática

Crie um contêiner que:

  • Utilize display: flex.
  • Centralize os elementos.
  • Adicione espaço entre os itens.
  • Permita a quebra de linha.
